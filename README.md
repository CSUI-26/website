# <div align="center">CSUI 2026</div>

Repositori ini menyimpan source code dari website CSUI angkatan 2026.

## Developing

Proyek ini menggunakan:

* Bun, package manager dan runtime
* Astro, generator
* React, UI framework
* Tailwind, styling library
* Biome, linting (`bun lint`) dan formatting (`bun format`)

### Local development

1. Clone repositori
2. Install dependencies (`bun i`)
3. Run `bun run sync` untuk melakukan pre-generasi type dan definisi khusus Astro (lihat baris 4 [tsconfig.json](tsconfig.json))
